# Functional scope

Institution: Bicol University Polangui.

- Administrator and gate-account login roles; student/employee registries with catalogue fields and private portraits.
- One username/password login per gate, active gate enforcement and external university shift scheduling.
- Database-assigned credential labels, checked destination, random NDEF references, matching read-back and activation.
- Immutable credential ownership/history, selected active credential, revocation and lost/damaged replacement.
- Server-detected Entry/Exit per operating day, configurable Manila cutoff, duplicate suppression, stable request recovery and no fabricated Exit.
- Persistent supported-phone reader, explicit activation/stop/recovery, rejected-tag feedback and no per-person direction/confirmation controls.
- Effective passage history, appended corrections, reconciled monitoring, private exports and presence estimates.
- Bounded anomaly detection/review, idempotent Missing Exit processing and explicit scheduler setup.
- Optional restricted aggregate summaries with review and no paid fallback.
- Responsive dark/light interface, accessible fields/statuses/tables and clear unsupported-device behavior.
- Local isolated MySQL and guarded PostgreSQL cloud configuration, narrow runtime grants, verified TLS and private external storage.
- Separate test/simulator/hardware workspaces, protected secrets and encrypted owned-target restore drills.

The application records credential scans. It does not independently verify a holder's identity, actual movement, occupancy, class attendance or misconduct. Safari/iOS NFC and unspecified hardware/native integrations are outside the browser scanner's supported capabilities.
